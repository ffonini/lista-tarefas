# Lista de Tarefas Full Stack

Primeira projeto full stack desenvolvido para estudo

A aplicação foi composta por:

- Backend desenvolvido com Node.js e Express
- Frontend desenvolvido com React
- API REST para gerenciamento das tarefas
- Persistência inicial utilizando arquivo JSON

O backend permite criar, listar, pesquisar, atualizar e excluir tarefas

## Tecnologias utilizadas

### Backend

- Node.js
- Express
- CORS
- Dotenv
- API REST
- Módulo nativo Crypto para geração de UUID
- Módulo nativo File System para leitura e gravação de arquivos
- JSON para persistência local dos dados
- Middlewares para validação e tratamento de erros

### Frontend

- React
- Vite
- JavaScript
- JSX
- HTML semântico
- CSS
- Fetch API
- React Hooks: useState e useEffect

## Funcionalidades do backend

- Criar uma tarefa
- Listar todas as tarefas
- Buscar uma tarefa pelo ID
- Editar o título de uma tarefa
- Alterar o status da tarefa
- Excluir uma tarefa
- Buscar tarefas pelo título
- Filtrar tarefas concluídas ou pendentes
- Validar os dados recebidos
- Salvar as tarefas em um arquivo JSON
- Retornar erros em formato JSON
- Liberar o acesso do frontend utilizando CORS
